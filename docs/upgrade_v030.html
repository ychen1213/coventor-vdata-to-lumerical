这次升级怎样更快读取，又怎样减少规则平面的面数？

先读完整转换教程，这里接着说明三个不同步骤的升级：裁剪时减少保存的记录；对已生成的严格平面重新划分；需要时用活跃块跳过无界面扫描。它们可以分别选择，收益和成本分别测量。

默认生效：解压时直接保存所选区域

以前先写全量体素数组，再切出ROI；现在仍解压、校验全部源，但只将XYZ裁剪范围内的记录写入缓存。材料三字节和可选平面四通道都保留原值。源坐标和区域坐标分开，避免第二次裁剪或加两次原点。

python run.py convert input.vdata --output new_crop --storage compact `
  --crop-um XMIN XMAX YMIN YMAX ZMIN ZMAX

将六个大写名称换成输入世界坐标系中的实际数字，单位微米，边界需在原体素面上。--max-raw-gib仍限制完整源，ROI外坏记录也会拒绝。XML DOM仍完整保留，独立压缩块索引快读尚未加入。

显式选择：保持边界的规则平面重三角化

MC已经生成表面后，优化器寻找所有X/Y/Z方向严格共面、同向连通的patch，使用精确二进制有理数判断凸性。仅单闭环的凸区域会替换；边界每个原顶点与边都保留，新中心复制原平面坐标。孔洞、凹区域、倾斜平面和曲面保持原样。

python run.py convert input.vdata --output new_planar --storage compact --planar-optimize
python run.py export-planar new_planar
python run.py export-stl new_planar

第一条先生成并优化紧凑网格，后两条按需导出。--planar-min-faces默认128。三角形变少意味着数组改变，保持的是符合条件的已有平面几何；VMESH无损则指把优化后的数组可逆保存。它不会消除原重建的误差。

完整AH53接受5块：两个X侧面、两个Y侧面和底面。全局闭合、面绕序、非流形边、退化、Euler、连通组件、面积、体积和包围盒检查通过；任何最终约束失败就整体回退。该方法限于一个实际导出实体，不独立改动多个接触材料的接口。

已有网格时，直接复用它

python run.py optimize-mesh existing.vmesh --output smaller.vmesh
# 索引NPZ也支持，输出仍为新VMESH
python run.py optimize-mesh existing.npz --output smaller.vmesh --min-faces 128

这个命令不读VDATA，也不重新MC；拒绝覆盖已有文件，不修改原输入。输出是独立网格归档，不会自动改写旧转换目录的manifest或生成CAD工程。重复优化会继续按相同条件审核；无可优化区域时保留原几何。

实验选项：活跃块减少MC扫描，但增加一个mask

python run.py convert input.vdata --output new_active --storage compact --active-blocks

在原全局padding场上，按32×32×8个计算单元检查min/max，保守保留跨阈值块及共享邻域，再调用同一次Lewiner MC。不会在分块边缘增加封口，测试与实际模型的顶点和面数组均一致。

完整fraction的三轮提取阶段中位数约7.184→6.751秒，MC内核约3.607→2.860秒；但增加58.47MB的布尔mask，峰值工作集约885.44→943.90MB。小ROI的vof略慢，plane基本不变。因此默认关闭；它不减少输出面数、浮点场或后续几何审核。

和QEM、材料及验证之间的关系

若同时指定--planar-optimize --reduction 0.45，先做保平面的重划分，再由QEM移除剩余面的45%。QEM会引入额外形变，采样误差限制仍只约束其相对于这张输入网格的附加采样距离。

多材料共享界面、全局包含/Mesh Order自动分配、Flying Edges与独立压缩块索引还属于后续工作；本版不宣称实现。转换仍不调用Coventor SDK，也不启动Lumerical。已生成MAT/LSF通过离线数组验证，未做实际CAD导入或光学收敛验证。
